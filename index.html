Welcome to my financial analysis website

This website provides interactive calculators for three important investment measures: holding-period return, annualized return, and portfolio return. Enter your own numbers, calculate results instantly, and see the formulas used.

Financial Analysis

Enter investment values below. Each tool shows the calculation method, assumptions, and the resulting percentage. These examples assume no taxes, fees, or additional cash flows unless explicitly included.

1. Holding-Period Return

Total return over the time you hold an investment, including cash income received.

HPR = (Ending value − Beginning value + Income) ÷ Beginning value × 100%

2. Annualized Return (CAGR)

Compound annual growth rate for an investment held over a specified number of years.

CAGR = [(Ending value ÷ Beginning value)^(1 ÷ Years) − 1] × 100%. Assumes no interim deposits, withdrawals, or distributions.

3. Two-Asset Portfolio Return

Weighted average of two assets' returns over the same period.

Portfolio return = (Weight A × Return A) + (Weight B × Return B), with weights converted from percentages to decimals. Weights must total 100%.

Interpretation notes

  • A positive return indicates a gain; a negative return indicates a loss.
  • Holding-period return is not necessarily annualized.
  • CAGR measures a constant equivalent annual growth rate, not each year's actual return.
  • Portfolio return here assumes a beginning-of-period allocation and no rebalancing during the measurement period.
